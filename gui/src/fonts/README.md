# Vendored fonts

`Inter` and `Space Grotesk`, both under the SIL Open Font License 1.1, which
permits redistribution as part of a bundled application.

- `inter.woff2` — variable, latin subset, covers weights 400–600
- `space-grotesk.woff2` — weight 500, latin subset

They are embedded rather than fetched from Google Fonts so the app renders in
its own typefaces offline. Refresh them with the latin `woff2` URLs from
`https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@500&family=Inter:wght@400;500;600`
requested with a browser user-agent.
